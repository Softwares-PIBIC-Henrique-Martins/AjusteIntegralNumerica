# AjusteIntegralNumerica
Trata-se de um  programa que realiza a integração numérica de uma função cuja integral não é uma solução analítica e efetua o ajuste sobre pontos plotados segundo a função obtida na integração, fornecendo os parâmetros de ajuste.

Link do vídeo no qual comento sobre o código e a aplicabilidade do software: https://www.youtube.com/watch?v=VeJE6uj-8xY
